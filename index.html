Relate × Mistral Vibe

Relate by Neo4j — an embedded, single-binary Cypher graph database — as a native Vibe plugin.

Get started

Paste this into Mistral Vibe to get started:

Set up the Relate graph database plugin for me:
1. Install the relate binary: curl -sSfL https://relatedb.ai/install.sh | bash
2. Install the plugin: curl -LsSf https://raw.githubusercontent.com/relatedb/relate-mistral/main/scripts/bootstrap.sh | sh
3. Tell me to run /reload-plugins, then wait for me.
Once it's loaded, work out what I seem to be building from my current project (its name, folders, files and any data in it). Whatever the domain, its data has connections in it. Propose one or two graphs that capture the most useful relationships in my domain, as a sketch of the nodes and relationships. Show a few example Cypher queries that would answer real questions about it. Don't create any data yet: ask which one I'd like to try.

Prefer to do it yourself? The manual steps are below.

Install

# 1. the relate binary
curl -sSfL https://relatedb.ai/install.sh | bash

# 2. the plugin into ~/.vibe/plugins/relate
curl -LsSf https://raw.githubusercontent.com/relatedb/relate-mistral/main/scripts/bootstrap.sh | sh

Then in Vibe: /reload-plugins (or a new session), and check /plugins and /mcp.

What a session gets

  • MCP tools mcp_relate.get_schema, mcp_relate.read_cypher, mcp_relate.write_cypher — served by relate serve --mcp stdio
  • Skills relate:relate (CLI, Cypher, storage, safety) and relate:relate-memory (graph as agent memory)
  • A session-start hook announcing Relate (fails open if the binary is missing)

Mistral Studio

Studio plugs Relate in as a custom MCP connector: run one live server — relate serve --database ./graph --mcp 7475 --auth relate:$TOKEN — behind a TLS proxy, then register https://graph.example.com/ at Studio → Context → Connectors with a static Authorization: Basic … header. Tools get_schema, read_cypher, write_cypher then work in conversations, agents and workflows (and can be shared to Vibe per workspace). Full recipe: docs/studio.md.
